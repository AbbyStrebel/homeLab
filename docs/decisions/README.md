# Architecture Decision Records

Short records of the non-obvious choices in this homelab, and *why* I made them.
Each one is cheap to write and gives the reasoning that config files can't.

Format (kept deliberately small):

```text
# <number>. <title>
Status: accepted | superseded | proposed
Context:  what situation forced a decision
Decision: what I chose
Consequences: what that costs me / what I gave up
```
